# Shallow Water Equations
This folder contains a numerical model of the shallow water equations implemented in Fortran, together with a Python script for visualizing simulation results.

## Contents
- `shallow_water.f90`: Fortran program for solving the shallow water equations numerically.
- `print_shallow_water.py`: Python script for plotting and comparing simulation results.

## Methods
- Finite difference methods
- A-grid and C-grid arrangements
- Runge–Kutta time integration
- Simulation of geopotential height and horizontal velocity fields

## Objectives
The project investigates the numerical simulation of shallow water dynamics and compares the results obtained using different grid arrangements.
This work is part of the `Numerical-PDEs` repository, which explores numerical methods for solving partial differential equations in meteorology and environmental sciences.
